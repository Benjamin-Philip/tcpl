* The Question
*Exercise 1-9*: Write a program to copy its input to its output, replacing each string of one or more blanks by a single blank.
* The Answer
This is similar to copying program. We maintain the previous and current character, and we don't print the current character if both the previous and current characters are spaces:

#+begin_src C :main no :tangle copy.c
#include <stdio.h>

main()
{
    int prevc, curc;

    prevc = 'a';
    while ((curc = getchar()) != EOF) {
        if (!((curc == ' ') && (prevc == ' ')))
            putchar(curc);

        prevc = curc;
    }
}
#+end_src

Testing:

#+begin_example
$ ./copy
The quick brown fox                    jumps over the lazy dogs.
The quick brown fox jumps over the lazy dogs.
#+end_example
