* The Question
*Exercise 1-8*: Write a program to count blanks, tabs and newlines.
* The Answer
This is just an extension of the line counting program with separate counters
for blanks, tabs and newlines:

#+begin_src c :tangle count.c :main no
#include <stdio.h>

/* count line in input */
main()
{
    int c, nb, nt, nl;

    nb = nt = nl = 0;
    while ((c = getchar()) != EOF)
        if (c == ' ')
            ++nb;
        else if (c == '\t')
            ++nt;
        else if (c == '\n')
            ++nl;
    printf("%d %d %d\n", nb, nt, nl);
}
#+end_src
