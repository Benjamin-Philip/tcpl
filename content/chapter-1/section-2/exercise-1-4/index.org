* The Question
*Exercise 1-4*: Write a program to print the corresponding Celsius to Fahrenheit
table.
* The Answer
When we take the formula for Celsius, \(C = \frac{5}{9}(F - 32)\), and solve for Fahrenheit, we get:

\[F = \frac{9}{5}C + 32\]

Thus, we must simply exchange ~celsius~ and ~fahr~ in our previous program, and
simply update the calculation for ~fahr~:

#+begin_src C
#include <stdio.h>

/* print Celsius-Fahrenheit table
   for celsius = 0, 20, ..., 300 */
main()
{
    float fahr, celsius;
    int lower, upper, step;

    lower = 0; /* lower limit of temperature table */
    upper = 300; /* upper limit */
    step = 20; /* step size */

    printf(" C     F  \n");

    celsius = lower;
    while (celsius <= upper) {
        fahr = ((9.0 / 5.0) * celsius) + 32;
        printf("%3.0f %6.1f\n", celsius, fahr);
        celsius = celsius + step;
    }
}
#+end_src
