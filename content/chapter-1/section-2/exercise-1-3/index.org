* The Question
*Exercise 1-3*: Modify the temperature conversion program to print a heading above
the table.
* Solution
We can print the heading before we starting computing and printing the table.
With some manual formatting, we can centre justify the headings relative to
their columns:

#+begin_src C
#include <stdio.h>

/* print Fahrenheit-Celsius table
   for fahr = 0, 20, ..., 300 */
main()
{
    float fahr, celsius;
    int lower, upper, step;

    lower = 0; /* lower limit of temperature table */
    upper = 300; /* upper limit */
    step = 20; /* step size */

    printf(" F     C  \n");

    fahr = lower;
    while (fahr <= upper) {
        celsius = (5.0 / 9.0) * (fahr - 32);
        printf("%3.0f %6.1f\n", fahr, celsius);
        fahr = fahr + step;
    }
}
#+end_src
